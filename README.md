# Titanic Dataset EDA

## Description
A Jupyter Notebook performing Exploratory Data Analysis (EDA) on a mocked Titanic dataset using Pandas, Matplotlib, and Seaborn.

## Features
- Descriptive Statistics 
- Demographic Visualizations (Age Distribution)
- Survival Metrics Analysis

## How to Run
1. Install dependencies: `pip install pandas numpy matplotlib seaborn jupyter`
2. Run notebook: `jupyter notebook eda_titanic.ipynb`

## Resources
- **Dataset**: `titanic.csv` (Downloaded locally from datasciencedojo repository)
